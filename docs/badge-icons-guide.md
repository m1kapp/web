# m1k 달성 뱃지 아이콘 가이드

## 스펙

- **포맷**: SVG (인라인 path로 배지 SVG에 삽입할 예정)
- **크기**: 16x16px 뷰박스 (`viewBox="0 0 16 16"`)
- **컬러**: 단색 (`currentColor` 또는 `#fff`)
- **스타일**: 심플 플랫, 선 굵기 1.5~2px, 라운드 캡
- **배경 없음**: 아이콘만 (배지 라벨 영역에 들어감)

## 사용 위치

### 1. 배지 SVG 안 (외부 임베드)
```svg
<svg width="80" height="20">
  <!-- 라벨 영역 안에 아이콘 삽입 -->
  <g transform="translate(4, 2) scale(0.9)">
    <!-- 여기에 16x16 아이콘 path -->
  </g>
  <text x="22" y="14">m1k</text>
  ...
</svg>
```

### 2. 웹 대시보드 (앱 안)
- 배지 월드 탭의 달성 아이콘
- 대시보드 수집 뱃지 컬렉션
- 배지 설정의 이모지 선택 UI

## 출력 형식

각 아이콘을 개별 SVG 파일로:
```
public/icons/achievements/
├── sprout.svg      (새싹)
├── chick.svg       (병아리)
├── fire.svg        (불꽃)
├── star.svg        (스타)
├── crown.svg       (왕관)
├── diamond.svg     (다이아)
├── trophy.svg      (트로피)
├── rocket.svg      (로켓)
├── turtle.svg      (거북이)
├── rabbit.svg      (토끼)
├── eagle.svg       (독수리)
├── dragon.svg      (용)
├── sun.svg         (맑음)
├── rainbow.svg     (무지개)
├── lightning.svg   (번개)

```

SVG 내용 예시:
```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 16 16" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round">
  <!-- path 데이터 -->
</svg>
```

## 디자인 톤

- **m1k 브랜드**: 귀엽고 심플, 한국적 감성
- **참고**: 토스 이모지(tossface) 느낌의 따뜻하고 둥근 스타일
- **단색이지만 캐릭터성** 있게
- 16px에서도 알아볼 수 있는 **명확한 실루엣**
- 너무 복잡하지 않게, path 포인트 최소화
