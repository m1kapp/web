# m1k

> mini make 1k — 방문자 1,000명을 향한 첫걸음

나의 사이드 프로젝트, 블로그, 깃허브 레포에 방문자 배지를 달고
**1,000명 목표 달성까지의 여정**을 한눈에 확인하세요.

## 뭐하는 서비스?

README나 블로그에 배지 하나 붙이면 끝.
방문할 때마다 카운트가 올라가고, 대시보드에서 통계를 볼 수 있어요.

```md
[![Hits](https://m1k.vercel.app/badge/my-project.svg)](https://m1k.vercel.app/my-project)
```

## 주요 기능

- **배지 임베드** — URL 하나로 방문자 카운트 시작
- **1K 프로그레스** — 1,000명 목표 달성률 시각화
- **잔디 히트맵** — GitHub 잔디처럼 일별 방문 현황
- **방문자 분석** — 국가, 디바이스, 리퍼러 자동 수집
- **중복 제거** — IP 해시 기반 하루 1회 카운트 (정직한 숫자)

## hits.sh와 뭐가 달라?

| | hits.sh | m1k |
|---|---|---|
| 카운트 방식 | 무조건 +1 | IP 해시 중복 제거 |
| 분석 | 숫자만 | 국가, 디바이스, 리퍼러 |
| 시각화 | 캘린더 히트맵 | 잔디 + 프로그레스 바 |
| 목표 | 없음 | 1,000명 달성 게이미피케이션 |
| 언어 | 영어 | 한국어 |

## 기술 스택

- **Next.js 16** (App Router)
- **Tailwind CSS v4** + **shadcn/ui**
- **Neon** (PostgreSQL)
- **Vercel** (호스팅)
- Clerk / Auth.js (인증)

```bash

npm run dev
```
